
Thank you for installing Refrakt!

Refrakt is a framework for building loosely coupled, maintainable, and testable XAML applications in WPF, maintained by Kemtix.

## Support & FAQ

1) License: Refrakt is distributed under the MIT License, this means "AS IS", WITHOUT WARRANTY OF ANY KIND.

2) XAML: declare the Refrakt namespace with xmlns:refrakt="http://refraktlib.com/".

3) Reporting Bugs: please search the open and closed issues first, then open a new issue with a sample project that reproduces the problem. https://github.com/kemtix/Refrakt/issues
